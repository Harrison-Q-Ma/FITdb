# FITdb

This repository is the accompanying repository for code used for processing datasets described in [FITdb](https://doi.org/10.64898/2026.07.28.741304). 

--- 

### Required packages
- `Python >= 3.10`
- `Scanpy`
- `Cellbrowser`
- `MAGeCK`
